# ☕ Aroma Café <a href="https://deborag-alves.github.io/cafeteria/cafeteria.html">(Acessar)</a>

Um site moderno de cafeteria desenvolvido com foco em apresentação visual de produtos e organização de layout.

---

## 📌 Sobre o projeto
O **Aroma Café** é um projeto front-end que simula o site de uma cafeteria, exibindo cafés, tortas e outras opções de forma simples, clara e visualmente agradável.

O objetivo principal é demonstrar habilidades em estruturação HTML e organização de conteúdo para web.

---

## 🚀 Tecnologias utilizadas
- HTML5
- CSS3

---

## 💡 Funcionalidades
- ☕ Exibição de produtos (cafés e tortas)
- 🖼️ Uso de imagens para melhor experiência visual
- 💬 Seção de comentários de clientes
- 📱 Layout organizado e intuitivo
